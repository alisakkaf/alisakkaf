### 👨‍💻 About My Work & Expertise

I am a specialized software developer and security researcher with a deep focus on **Hardware Security Protocols** and **Low-Level Programming**. My daily operations revolve around dissecting proprietary mobile firmware, analyzing complex boot sequences, and developing automated tools that interact directly with physical hardware logic.

Beyond writing code, I actively engage in **Vulnerability Research**, analyzing CVEs, decompiling APKs, and writing Proof-of-Concept (PoC) exploits. I build robust, commercial-grade desktop applications designed to simplify complex hardware operations for mobile technicians and security professionals worldwide.

**Core Focus Areas:**
* **Reverse Engineering:** Deep analysis using IDA Pro and Ghidra to understand undocumented OEM protocols and encryption layers.
* **Desktop Solutions Architecture:** Building high-performance, multi-threaded GUI applications using **C++ & Qt Framework**.
* **Mobile Security Bypass:** Researching and developing safe methods to disable factory protections (FRP, MDM, KG) by interacting with low-level partitions (NVRAM, EFS, dtbo).

### ⚔️ Featured Projects & Research

#### 📱 **Mysterious-Dev Tool**
A massive, multi-brand servicing utility architected for advanced mobile diagnostics and repair. 
* **Architecture:** Developed entirely in **C++ and Qt**, ensuring rapid execution and a seamless user experience. Connected to a custom **PHP/MySQL** backend for real-time license validation.
* **Security Implementations:** Utilizes strong RSA/AES encryption for server-client data transmission to prevent payload interception.
* **Core Capabilities:** Automates the injection of custom loaders (Firehose/DA), executes direct memory read/write operations, and safely disables system-level locks across various OEM environments.

#### 🛡️ **Vulnerability Analysis & Reverse Engineering**
* **Protocol Analysis:** Documenting and mapping undocumented USB communication protocols utilized by major smartphone manufacturers.
* **Exploit Development:** Creating Python-based Proof-of-Concepts (PoCs) for bypassing secure boot constraints and demonstrating logic flaws in BootROM implementations.
* **APK Modification:** Advanced decompilation, deep patching, and recompilation of Android application packages for security testing and feature modification.
